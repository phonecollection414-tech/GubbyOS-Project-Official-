# 💻 GubbyOS
Site web : https://phonecollection414-tech.github.io/GubbyOS-Project-Official-/
### Think easy. Live simple. Every day.

**GubbyOS** est un système d'exploitation expérimental créé par T.G. Son objectif : proposer une expérience informatique simple, accessible et agréable, avec un environnement qui évoluera progressivement.

## 🖥️ Que contient GubbyOS ?

La version actuelle, **0.1 Dev**, constitue le début du projet.

Elle comprend :
- Un secteur de démarrage (Bootloader).
- Un noyau expérimental au format x86 (i386).
- Une image système amorçable.
- Une compatibilité de test avec VirtualBox.

## ⚙️ Que pourra faire GubbyOS ?

À terme, GubbyOS ambitionne de proposer :
- Un bureau graphique avec des icônes.
- Un menu principal inspiré de Windows.
- Des applications intégrées.
- Une interface simple et intuitive.
- Un environnement personnalisable.
- Un système conçu pour évoluer avec de nouvelles fonctionnalités.
