▶️ Démarrer avec VirtualBox 6.1

  1. Éteignez complètement la machine virtuelle.
  2. Ouvrez Configuration → Stockage.
  3. Ajoutez un contrôleur de disquette I82078.
  4. Ajoutez un lecteur de disquette et sélectionnez gubbyos.img.
  5. Dans Système → Ordre d'amorçage, activez Disquette.
  6. Démarrez la machine virtuelle.

Important : le fichier est une image de disquette (.img), pas une image DVD/ISO.
